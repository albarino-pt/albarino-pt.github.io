A full-stack web platform built for a Portuguese fire station to manage shift scheduling, fleet operations, firefighter availability and payroll — replacing a mix of spreadsheets and WhatsApp coordination with a single system.

The platform has two sides: a **management dashboard** for station admins (shift calendars, fleet status, user management, GDPR request handling) and a **self-service portal** for firefighters (check upcoming shifts, swap shifts with colleagues, log availability, track earnings, access vehicle info behind a daily-rotating security code).

Built with Astro, TypeScript and Supabase (Postgres + GoTrue auth), self-hosted. PWA-enabled with push notifications so crews get notified of shift swaps and schedule changes in real time.

### Key features

- Shift ("piquete") calendar with Portuguese holiday recognition
- Peer-to-peer shift swap requests with approval workflow
- Fleet management with a daily-rotating access code for vehicle info
- Availability tracking and payroll/earnings dashboard
- Push notifications (PWA) for real-time updates
- GDPR request handling built into the admin side
